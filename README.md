# AURAFITS – Luxury Fashion E-Commerce Website

AURAFITS is a modern luxury fashion e-commerce frontend website built using HTML, CSS, and JavaScript.  
The project showcases stylish UI design, responsive layouts, dynamic product rendering, and interactive shopping features inspired by real-world fashion platforms.

---

## ✨ Features

- Luxury modern UI design
- Responsive design for Mobile, Tablet, and Desktop
- Dynamic product rendering using JavaScript
- Separate Men, Women, and Kids sections
- Product search functionality
- Wishlist feature
- Smooth scrolling effects
- Interactive category-based shopping
- Clean product card layouts
- Organized folder structure

---
